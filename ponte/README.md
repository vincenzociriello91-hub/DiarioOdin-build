# Ponte veloce Claude-Odin

Worker Cloudflare `odin-ponte`: connettore MCP per Claude e coda dei comandi per la Odin (modulo Magisk, `ponte.sh`).
Si pubblica da solo con `.github/workflows/ponte.yml` quando cambia questa cartella. Esito in `esiti/ultimo.txt`.

Strumenti: `odin_esegui`, `odin_risultato`, `odin_stato`, `odin_salute` (script in `salute.txt`), `odin_schermo` (script in `schermo.txt`: foto dello schermo rimpicciolita con il Python di Termux e caricata su `/odin/blob`).
